### 题意
小明从 \(1\) 号站点开车到 \(n\) 号站点。已知第 \(i\) 个站点到第 \(i+1\) 个站点的距离为 \(v_i\)，第 \(i\) 个站点的油价为 \(a_i\)。汽车油箱容量无限大（意味着只要有钱，想买多少买多少），每升油可以跑 \(d\) 公里。求到达终点所需的最小总花费。

---

### 解析

观察题目，因为油箱容量是无限的，所以我们的贪心策略很直接：**如果当前面临缺油的情况，我们总是希望在之前经过的所有加油站中，挑一个油价最便宜的加油站买油。**

为什么叫“反悔贪心”？因为我们在走到第 \(i\) 个站点时，虽然之前可能已经开过去了，但我们利用数据结构的特性，假装**“反悔”**，回到之前那个最便宜的站点去买油。

**具体步骤：**
1. 我们维护一个**小根堆**（优先队列），用来存放从起点到当前站点 \(i\) 经过的所有加油站的油价。
2. 维护一个变量 `tot`，表示我们当前拥有的油量理论上能跑的**总距离**。
3. 遍历站点 \(i\) （从 \(1\) 到 \(n-1\)）：
   * 将当前站点的油价 \(a_i\) 压入小根堆。
   * 如果 `tot >= v[i]`，说明当前油箱里的油足够跑到下一个站点，不需要买油，直接跳过。
   * 如果 `tot < v[i]`，说明油不够了，缺的距离是 `v[i] - tot`。
   * 此时，我们从堆顶取出最便宜的油价，计算需要买多少升油。由于油箱按升买（或者说是按整数单位买），我们需要**向上取整**：`need = (v[i] - tot + d - 1) / d`。
   * 更新花费：`ans += need * q.top()`。
   * 更新总油量：`tot += need * d`。

---

### 复杂度分析

* **时间复杂度**：每个站点的油价最多入堆一次、出堆一次，优先队列单次操作时间复杂度为 \(O(\log n)\)。遍历 \(n\) 个站点，总时间复杂度为 **\(O(n \log n)\)**。对于 \(n \le 10^5\) 的数据范围，稳过。
* **空间复杂度**：需要数组存储距离和油价，以及一个优先队列。空间复杂度为 **\(O(n)\)**。

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
long long n,d,v[100005],a[100005],ans;//答案可能超过2^32
int main()
{
    cin >> n >> d;
    for (int i = 1;i < n;i++)
    {
        cin >> v[i];
        v[i] += v[i - 1]; // v[i] 表示从起点到第 i+1 个站点的总距离
    }
    for (int i = 1;i <= n;i++)
        cin >> a[i];
    // 小根堆，维护当前经过的加油站中，最便宜的油价
    priority_queue<int,vector<int>,greater<int> > q;
    long long tot = 0; // 当前已经买过的总油量（能跑的总距离）
    // 只需要考虑到第 n-1 个站点，因为第 n 个站点不需要再买油了
    for (int i = 1;i < n;i++)
    {
        q.push(a[i]); // 把当前站点的油价加入优先队列
        // 如果当前的总油量已经能够到达第 i+1 个站点，则不需要买油
        if (tot >= v[i]) continue;
        // 计算还需要买多少油（向上取整）
        // 等价于 ceil((v[i] - tot) / d)
        long long need = (v[i] - tot + d - 1) / d;
        ans += need * q.top(); // 花最便宜的价格买油
        tot += need * d;       // 更新总油量
    }
    cout << ans << endl;
    return 0;
}
```

### 注意事项
1. 十年OI一场空，______________。

2. 15行的`greater<int>`和`priority_queue`的两个右尖括号之间最好打一个空格，有些编译器会读成 `>>`。

3. 慎用`ceil`,整数之间向上取整最好用`(a + b - 1) / b`。
